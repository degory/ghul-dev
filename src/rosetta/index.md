# Rosetta Code

[Rosetta Code](https://rosettacode.org) sets the same task in many languages, which makes it a
fair way to see what a language reads like beside its neighbours. Every solution here is posted
there too, and each one is built and run by a test in
[ghul-rosetta-code](https://github.com/degory/ghul-rosetta-code) before it goes anywhere.

Each one can be edited and run here: click the pencil, change it, and run it in your browser.
