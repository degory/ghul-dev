# Rosetta Code

ghūl solutions to [Rosetta Code](https://rosettacode.org) tasks. Every one is built and run by a
test in [ghul-rosetta-code](https://github.com/degory/ghul-rosetta-code), and each can be edited
and run here: click the pencil, change it, and run it in your browser.
